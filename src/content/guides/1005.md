> 图片会进优化管线（转成 webp、去掉 EXIF）。

## 一、起后台

```bash
pnpm dev
```

打开 `http://localhost:4321/keystatic`。后台只在这台机器上的 `pnpm dev` 里存在，公网上没有这个地址。

## 二、写一条

在左侧选一个集合（研究稿 / 问答 / 教程 / 提示词），新建一条。地址会自动取全站统一的下一个号。
标的、标签、智能体、模型都是下拉或勾选，不用手打 —— 手打的东西会长出同义的写法。

也可以走「粘贴导入」：把模型的输出整理成 JSON，粘进 `http://localhost:4321/_import`，
生成一条字段填好的草稿。

## 三、过闸

`http://localhost:4321/_gate` 会用和构建期同一份判据扫一遍。命中事实类的说法（第一人称 ＋ 持有 / 成本 / 数量）
就发不出去，只能改文案；命中意图类的只提醒。

## 四、提交推送

`http://localhost:4321/_publish` 只提交内容目录下的改动，提交之前 pre-commit 那道闸照跑。
推上去之后，部署平台跑 `pnpm build`，第一步又是发布闸。

## 五、确认上线

构建过了，站上就是新的；没过，站上留着上一个版本。两种情况都不会出现"发了一半"。
