# 发版规范

> 【2026-09-21 立的】在这之前，「什么样才算能发」这件事**没有写在任何地方**，
> 也没有一处机器守着全部：发布闸只管泄露，`pnpm test` 哪一层都不在，
> 353 条测试全红也照样能发版 —— 因为 Cloudflare 跑的只是 `package.json` 里那条
> `build` 链子，而仓库里没有 CI。这份文档说的是补上之后那套东西。

三份相邻文档各管一段，别在这里找错地方：
[gate.md](gate.md) 是**泄露**那一道的全部细节，[deploy.md](deploy.md) 是
Cloudflare 那一侧（域名、构建命令、统计），[content-model.md](content-model.md)
是字段和集合。这一份只回答一个问题：**一次发版要过哪些关，哪些机器守、哪些人守。**

## 1. 一次发版长什么样

```
   后台写稿（pnpm dev · /keystatic）
        │
        ├─ 人：自己点开那一条看一眼（机器守不住，见第 4 节）
        ▼
   落盘 src/content/**
        │
        ├─ ① pre-commit ── 发布闸（暂存区）   ← 泄露
        ├─ ② pre-commit ── 稿件体检（暂存区） ← 坏页面
        ▼
   git commit → push（进私有仓库）
        │
        ▼
   Cloudflare 构建，跑的就是 pnpm build：
        ├─ ③ 发布闸（工作树全量）        ← 泄露，绕不过
        ├─ ④ 稿件体检（工作树全量）      ← 坏页面，绕不过
        ├─ ⑤ pnpm test（387 条）        ← 判据自己还对不对
        ├─ ⑥ astro check                ← 类型
        └─ astro build → pagefind → 上公网
```

**两处都卡是刻意的**：① ② 给即时反馈（写完就知道），③ ④ 绕不过
（`--no-verify` 跳过的钩子，Cloudflare 上会再碰一次）。
少了前者，问题要等到部署时才报；少了后者，它就只是一个提醒。

### 顺序是按「错了有多贵」排的，不是按跑得快排的

| 关 | 错了的代价 |
|---|---|
| 发布闸 | **发出去就收不回来**（网页被抓过一次，撤回也撤不干净） |
| 稿件体检 | 读者看到一页坏掉的稿子；或者作者自己回头**改不动**那一条（后台编不开） |
| pnpm test | 判据坏了还没人知道 —— 上面两道靠它才是真的 |
| astro check | 类型错误，修一下再发 |

所以闸门永远排第一。这个顺序有测试钉着（`coverage.test.ts` 和
`formatRules.test.ts` 的 E 组），删掉链子里任何一条都会红 ——
**因为删掉它本身是零症状的**：测试全绿、构建全绿、站照发。

## 2. 机器守的（四道，都没有开关）

| 关 | 跑什么 | 拦什么 | 放过什么 |
|---|---|---|---|
| 发布闸 | `pnpm gate` / `gate:staged` | 仓位、成本、券商账户、凭证、内网系统名（block 档） | warn 档只报不拦；草稿不拦但会列出来 |
| 稿件体检 | `pnpm content:check [--staged]` | 空正文、被吃掉的分隔线、后台编不开的裸 `<`（block 档） | 正文里的一级标题、会原样印出来的反斜杠、来源没标 → warn，**不拦** |
| 测试 | `pnpm test` | 任何一条红 | —— |
| 类型 | `astro check` | error | warning / hint |

**四道都没有跳过的办法**：没有环境变量、没有 `--force`、没有第二个参数。
一个能被关掉的检查，迟早会在赶时间的那天被关掉（[engineering-notes.md](engineering-notes.md) 红线 3）。
`--staged` 换的是**读哪份字节**（索引 vs 磁盘），不是要不要查。

### 稿件体检看的六种写法

判据在 `scripts/content/formatRules.ts`，每一条后面都跟着一次真出过的事：

| 码 | 档 | 症状 |
|---|---|---|
| `empty_body` | block | 【2026-09-21】`/posts/8` 建出来 `draft: false` 正文全空，闸门绿、astro check 绿、构建绿，站上一页只有标题 |
| `setext_eaten` | block | 一段文字下一行写 `---`，那段话**变成 `<h2>`**、分隔线消失，零报错（实测） |
| `bare_lt` | block | 裸 `<` 后跟字母 / 数字 / `!` → 后台那一条**编不开也改不了**（坑 19），而站上和构建全绿 |
| `h1_in_body` | warn | 章节写成 `#`，目录只收 h2/h3 → 那些段落不进目录，页面照画 |
| `stray_backslash` | warn | 【2026-09-21 查实】模型把算式写成 LaTeX，而站上没装数学渲染 —— `dist/r/1002/index.html` 里印出来的就是 `14.94\%$`，连反斜杠一起 |
| `unlabeled_source` | warn | `agent` / `model` 还没标，站上印「来源未标注」—— 合法的一档，但多半是忘了 |

★ **block / warn 两档不许互换着用**。把 warn 提成 block，会让"还没来得及标"
变成发不出去，人就会去找绕过的办法；把 block 降成 warn，则是明知页面是坏的还发。

★ `stray_backslash` **长期就在 warn 档 —— 这是个决定，不是在等一次清理**。

【2026-09-22 站长定的】它立起来那天（前一天）写的是"有期限的妥协：那 7 份
（posts 1002 / 1006 / 1008 / 1013 / 1015 / 1018、qa 1003，共 40 行）清干净就提成
block"。**一天之后那笔账从 7 份涨到 8 份** —— 新交上来的 1020.md 又带了 3 处。
源头是每天的模型输出，那不是一批存量，是**常流**；写着"有期限"而到期条件永远
不满足的规则，就是这个项目最在意的那种「以为有保障，其实没有」。

按 block / warn 的分法它本来也在 warn 这一侧：另外三条 block 各自**毁掉一样东西**
（一页没有正文 / 一整段被吃成标题、意思变了 / 作者从此改不动那一条），
而这一条**什么都没毁** —— 数字、单位、结论全在，多出来的是几根杠。难看，
但读者读得懂、作者随时改得动。拿它拦住发版，换来的是人去找绕过闸门的办法。

⚠ 所以 warn 档里现在有**两类**东西，别再把它读成单一的"待补"：
**「还没填完」**（来源没标、章节级别不对）和**「印出来难看，但读得懂、改得动」**。
屏幕上那句收尾也是照这个改的。
⚠ 它**不是**"可以不管"：warn 逐条列在屏幕上，正是为了让人顺手改掉 ——
改法每条命中里都写着（算式改成普通文字，或整段包进代码围栏）。
★【2026-09-22】其中**整行只有杠**的那一半（LaTeX 的换行）有一键清理：
`pnpm dev` 开着时打开 `/_tidy`，或者后台左侧菜单的「清理特殊字符」。
它**只碰整行只有杠的行** —— 算式里的 `3.76\\%` 不碰，那要改到数字旁边，
机器不该替人决定。判据 `scripts/content/tidyPlan.ts`，见 docs/engineering-notes.md 第四节。
⚠ 同一页上还有**另一档**（当天晚些时候加的，也是那一页改名的原因）：
转义掉的 `\*\*` —— 中文标点后面紧跟汉字时那段粗体根本没被解析，页面上印出来
就是两个星号。那一档**只去掉标记**，那一行别的字不动。它和 `stray_backslash`
**不是一回事**：`PRINTED_BACKSLASH` 刻意不认转义标点（`\<` `\{` 是 Keystatic
自己加的正解），所以稿件体检**不报**这一种，只有 `/_tidy` 上看得见。
⚠ 哪天真想提成 block，那是**重新做一次决定**（清干净 ＋ 确认新稿不再带 LaTeX），
不是自动到期。连 `formatRules.test.ts` 里那条"必须是 warn"的断言一起改。

★ 它判的是「**这根反斜杠会不会被印出来**」，不是「像不像 LaTeX」。照命令表
（`\approx` / `\mathbf` / `\frac`…）写的话，下一个模型换个命令就漏网而屏幕照常绿。
代价是**没有反斜杠的 `$P = 82.25$` 刻意不报** —— 这是个财经站，`$76～$79` 满站都是，
拿 `$…$` 当判据就是天天误伤。那条漏报是个决定，钉在 `formatRules.test.ts` 的 C 组。

★ `bare_lt` 那条的边界是**拿后台那个 MDX 解析器真的编过一遍量出来的**，
不是照 markdown 规范推的 —— 照规范推会同时多出两个漏网（自动链接、HTML 注释）
和一个误伤（四空格缩进）。改它之前先照 `formatRules.ts` 文件头那段重新量一遍。

## 3. 改这套东西的规矩

和改闸门规则表同一条（[gate.md](gate.md) 第 7 节）：

1. **改判据必须补测试**，用例从"人和模型真的会这么写"来 —— 不许照着正则反推。
2. **"不许误伤"那一组比"必须拦住"那一组更重要。** 这几道会拦住构建；
   误伤一次的代价不是难看，是**这条规则从此被绕过**。
   `formatRules.test.ts` 的 B 组每一行都是从站上真实稿子里抄的。
3. **写完"必须红"的用例，故意破坏一次看它红不红。** 这是唯一能证明它钉着东西的
   办法。这份判据立起来时 10 处破坏全实跑过（6 处接线 + 4 处判据），
   每一处都红在该红的那条用例上。
4. **改构建链就要改钉它的测试**，别让测试退化成恒真断言。

## 4. 机器守不住的（只能靠人）

这几条**没有任何东西能替你发现**，所以单独列在这里：

- **Cloudflare 控制台里那一行构建命令。** 它不在仓库里、没有版本、没人 review。
  填成 `astro build` 就等于把上面四道关全拆了，而站照常发布。
  见 [deploy.md](deploy.md) 2.2。**换人接手、换项目、改构建设置之后都要回去核一眼。**
- **每加一条内容，自己在后台点开看一眼。** 稿件体检只认已知的六种写法，
  但后台只有本机有，CI 永远不会替你打开那个编辑器（坑 19 的教训）。
- **数字自己回原始来源核对。** 模型会编数字，闸门和体检都不管这个
  （站上那句免责声明说的就是这件事）。
- **截图里的账号 / 余额 / 持仓。** 闸门只看文本，看不见像素（gate.md 第 8 节）。
- **`pubDatetime` 是 UTC**，站上按北京时间显示，差 8 小时。写成未来时间的稿子
  在 dev 里看得见、构建出来页面根本不生成，而且构建是绿的（坑 1）。
- **发版前别开着 dev server 跑 `pnpm build`** —— Windows 上会 EPERM（坑 5）。

## 5. 发出去之后发现不对

站是静态的，回滚就是**再发一次**：

1. 后台把那一条 `draft` 打开（草稿不生成页面），或者直接删掉。
2. 提交推送 —— Cloudflare 重新构建，那个地址变 404。
3. ⚠ **删稿之后留意 `public/pagefind`**：它在 .gitignore 里、只增不减，
   而 Pagefind 的 fragment 存的是**整页正文**。`pnpm build` 里那句
   `rm -rf public/pagefind` 必须排在 `astro build` 前面，否则一篇已经删掉的稿子
   的全文会被拷回去、下一轮再发上公网（`package.json` 的 `//build` 注释②，
   有测试钉着）。
4. 换地址的话去 `src/config/legacyUrls.ts` 加一行（**只增不改**），
   老链接才不会死。

> 已经被抓走的东西撤不回来。**这一节能救的是"页面坏了"，救不了"内容不该发"** ——
> 后者只有发布闸能救，而它站在提交那一刻的前面。
